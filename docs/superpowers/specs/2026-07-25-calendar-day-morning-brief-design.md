# PanLayer 全日历早参设计

## 目标

盘前早参按自然日运行，不再因为周末跳过。交易日保持现有五模块口径；周末生成带明确休市说明的五模块早参。当天记录尚未生成时，工作台临时展示最近一期通过结构校验的早参，并显示它自己的真实日期。

## 调度

- 一级资讯预采集、二级资讯预采集和盘前早参属于自然日任务，每天按北京时间运行。
- 盘中宽度、ETF 收盘指标和收盘复盘仍属于市场交易任务，周末不进入补跑队列。
- 新高初始化继续作为后台任务运行，但不得挤掉已经到期的早参任务。
- 周末调度器每次最多执行一个到期的早参关键任务和一个后台任务，沿用现有公平队列与幂等检查点。

## 内容真实性

- 周末提示词必须写明“A 股今日休市”，内容定位为周末资讯与下个交易日观察背景。
- 周末不得输出当日高开、低开、平开或盘中方向判断。
- 所有事实继续要求来源引用；缺少可靠来源时明确写“未查到可靠更新”。
- 不推荐个股，不给出买卖、仓位或收益建议。

## 展示回退

- 工作台先读取当天早参。
- 当天早参不存在或未通过结构校验时，读取不晚于当天的最近一期有效早参。
- 页面继续使用早参数据自身的 `date` 和 `generatedAt`，不得把旧早参伪装成当天内容。
- 精确日期 API 保持原语义，不对外静默返回其他日期。

## 健康状态

- 周末日度任务只统计资讯预采集、早参和后台初始化，不把六个盘中节点、ETF 收盘指标和收盘复盘标成逾期。
- 调度心跳、任务状态、来源和生成时间继续可追溯。

## 验收

- 星期六 08:17 的补跑队列包含早参，不包含盘中宽度、ETF 收盘指标或收盘复盘。
- 星期六早参提示词明确包含休市约束。
- 当天无早参时工作台展示最近一期有效早参，并保留原日期。
- 所有单元测试、构建与生产调度调用通过。
